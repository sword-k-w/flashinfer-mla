# B200 74/74 SM：独立重测结果

**本轮重新测量 prefill Sq=128 dense 性能，并分别采集 LTC 与 L2/memory。**

Prefill 性能：72 点，几何平均加速 **0.9925×**，localized 更快 12/72 点；最大 block 加速比波动 2.35%。
旧同拓扑参考的几何平均加速为 0.9915×，仅用于对照，本轮表格全部来自新数据。

LTC：36 份独立单指标报告，replay pass 数 [1]。
L2/memory：36 份独立十指标报告，replay pass 数 [4]。
L2 质量检查标记 8/36 条 mode/shape 记录；采集完成不代表这些记录是有效命中率。

L2 异常定义、两轮对照及单指标后续测量见 [完整记录](L2_HIT_RATE_NOTES.md)。
